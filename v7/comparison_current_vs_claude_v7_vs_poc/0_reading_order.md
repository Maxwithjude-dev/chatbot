## 동현 PoC 쪽에서 해주면 좋은 것
1. KURE-v1 모델이 있는 PC에서 `run_poc.py`의 3단계를 실제 임베딩으로 켜고 같은 평가셋으로 1회 측정 → "추정" 열을 실측으로 교체.
   (`run_poc.py`는 `taas_chatbot_poc` 폴더 옆에 두고, 경로 2곳만 맞추면 됨. `rapidfuzz`가 설치돼 있으면 `rapidfuzz_stub` import 줄은 삭제.)
2. 결합안 검토: PoC 서비스 골격 유지 + `matcher.py` 1·2단계를 Claude v7 규칙(`taas_nlu.py`)으로 교체, 3단계 KURE 유지.

## 주의
- 평가 질문·정답표는 AI(Claude)가 작성, 정답표는 검수 전.
- 채점 기준: 안내 메뉴 집합 = 정답 집합. 제한 메뉴(18개)는 '답변불가'로 통일.
- 운영 챗봇·원본 데이터는 변경하지 않음.
