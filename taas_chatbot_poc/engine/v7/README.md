# TAAS 챗봇 해석 규칙 — 최종본 v7 (2026-10-14)

## 1. 이 폴더가 무엇인가
개선안 중 **블라인드 측정이 가장 좋은 최종 버전(v7)** 의 해석 규칙과 사전만 모은 것입니다.
- 블라인드6(260문항, v7 고정 후 1회 채점): 현행 40.4% → **v7 88.8%**
- 운영 챗봇·원본 데이터(DOCUMENT_SET, KEYWORD_SET)는 변경하지 않았습니다. 이 폴더는 **그 위에 얹는 규칙**입니다.

## 3. 규칙이 어디에 있나 (taas_nlu.py 안)
| 이름 | 하는 일 | 예 |
|---|---|---|
| `ALIASES` | 표현 통일 | 따릉이→자전거, 안전띠→안전벨트, 형태벌→형태별 |
| `PROC_RE` | 업무 밖 판정 | 갱신·과태료·날씨·점심·택시 호출·아이디 |
| `STEM_RULES` | 활용형·구어 → 메뉴 (44개) | 죽었→사망사고, 최근 3년→추세, 내가 넣은 문의→나의민원 |
| `slots()` | 가해/피해/보행/보호구역 역할 판단 | 노인 운전자→1당노인, 자전거를 친 차→2당자전거, 자전거에 치인→1당자전거 |
| `NEG_ENT_RE`, `NEG_RE` | 부정어 | 음주운전 아닌 → 음주운전 제외 |
| `HIER`, `ABSORB`, `WEAK` | 겹치는 메뉴 정리 | 보행노인이 있으면 노인·보행은 버림 |
| `SEM_VETO` | 유사도 오안내 차단 | 좌회전→우회전보행사고 금지 |
| `YEAR_RE` | 연도 처리 | 2023년 제거, 2026년→실시간 제한 |

## 4. 실행 (원본 CSV 3개가 있는 `sources/` 폴더가 상위에 있어야 함)
```
python3 test_regression.py
python3 respond.py "노인 운전자 사고" "음주랑 과속 사고"
python3 serve.py --port 8765
```
전체 패키지(시험셋·결과·보고서 포함)는 `TAAS_챗봇개선_프로토타입_2026-10-14.zip`.
